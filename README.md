# AI Text Detection Feature Analysis

This Python script demonstrates a simplified approach to analyzing text for features that might indicate AI generation. It examines sentence length variation, word choice, common phrase usage, and punctuation density to provide a basic classification.

## Language

`python`

## How to Run

Save the code as a Python file (e.g., `ai_detector_demo.py`) and run it from your terminal using: `python ai_detector_demo.py`
